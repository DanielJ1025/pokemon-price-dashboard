# 포켓몬 카드 대시보드 — 제품화 시장성 리서치 (260908)

> 결론: **제품화 가능성 낮음 → 개인용으로 확정.** 아이디어·근거는 여기 보존.

## 질문
이 대시보드(스캔·시세·컬렉션)를 앱/웹으로 **판매** 가능한가? 국내/해외 버전, 카드 스캔 인식까지 붙이면?

## 결론 (요약)
- **빈 시장 아님(레드오션).** 글로벌·국내 모두 경쟁 포화.
- **포켓몬 IP 법적 리스크**가 수익화의 결정적 게이트(카드 이미지·상표).
- 개인용으로는 최고의 도구 → **개인용 확정.** 제품화는 보류.

## 경쟁 지형
### 글로벌
- **Collectr** (지배적): 무료 + PRO **$7.99/월 ($59.99/년)**, 무제한 스캔·5년 시세이력. 수백만 유저, DJ Steve Aoki 투자.
- TCG Collector, **Dex**(~$4/월, 컬렉션+덱빌더), Pokellector(세트 체크리스트), BindeX, Ludex($89.99/년), Dragon Shield.

### 국내 (대부분 2026 신상, 이미 다수)
- **CardLens** — Gemini AI로 카드 이름·번호·세트·레어도 추출 + **네이버쇼핑(쿠팡·11번가·G마켓·옥션·SSG·롯데)·너정다(ICU) 시세**. ← **우리 대시보드와 거의 동일 컨셉.**
- 푸카(Pooka), 카덱스(Kardex), 포켓시세스캔, PokiSon, Pokiframe, 포켓몬카드 시세/스캐너 등.

## 스캔/인식 현실
- 정확도: 모던 영문 **85~95%**, 빈티지·패럴렐 **60~80%**, **일본 카드 인식이 업계 최대 난제.**
- 직접 ML 개발은 부담 → **Gemini/Vision API로 카드번호·세트 추출**이 현실적(CardLens 방식).
- 전 세트/국내·해외 데이터: **콜렉토리 API가 kr/jp/us + 과거세트까지 제공**(현재 사용 중) → 데이터는 확보됨.

## ⚠️ 법적 리스크 (핵심 게이트)
- **The Pokémon Company가 Pokellector를 상표·저작권으로 제소한 전례.** 카드 이미지 무단 게시(Beckett 잡지 등)에도 공격적.
- **수익화 시 리스크 급증.** 기존 앱들은 ①"비공식·참고용 fair use" 고지 ②공식 제휴 부인 ③이미지 재현 최소화로 회피.
- 수익화하려면 이미지 비재현(사용자 업로드/외부 링크/라이선스 데이터), 명시적 고지 필수.

## 시장 규모 (참고)
- TCG 시장 $8.4B(2025) → **$16.9B(2035, CAGR 6.9%)**. 디지털/앱 유입 증가.

## 수익화 모델 (검증된 것)
1. **프리미엄 구독**(1순위·검증): 무료=기본, 유료=무제한 스캔·시세이력·**매물 알림**·클라우드 백업. 월 2~5천원.
2. 제휴 수수료(매물 링크→쿠팡파트너스; 국내 제휴 생태계 약함).
3. 광고(무료 유저) / B2B(카드샵 재고·시세 위젯).

## 만약 그래도 판다면 — 차별점(우리 무기)
경쟁자 대부분이 **안 하는** 것:
- 🔔 **정가 이하 정식몰 매물 실시간 알림**("발매가로 살 기회") — 이미 만든 감시기. 진짜 wedge.
- 🇰🇷 KR 실거래 정확도(콜렉토리+번개+너정다) + 🇯🇵 일본 원정구매 가이드(환율·시세 비교).
- 추천 경로: "매물 알림 + KR 시세 + 컬렉션"으로 좁힌 무료 웹 → 유저 확보 → 반응 보고 구독/앱. 스캔은 2단계(Gemini Vision).
